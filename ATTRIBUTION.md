# Third-party assets

## Muscle body-map polygons

The SVG polygon data used for the "Muscles worked" body map in `index.html`
(`BODY_POLY`) comes from:

- **react-body-highlighter** — https://github.com/giavinh79/react-body-highlighter — MIT License
- whose polygons originate in **react-native-body-highlighter** — https://github.com/HichamELBSI/react-native-body-highlighter — MIT License

The MIT License permits use, modification and redistribution with attribution.
The polygons here have been re-tagged with the muscle groups this app uses;
the coordinate data is unmodified. Model canvas is 100x200.
